# Adapted UI components

`src/components/ui/timeline.tsx` is adapted from [ReUI Timeline](https://github.com/keenthemes/reui/blob/main/registry-reui/bases/radix/reui/timeline.tsx).
Copyright (c) 2025 Keenthemes Inc.

`src/components/ui/choicebox.tsx` is adapted from [Kibo UI Choicebox](https://github.com/haydenbleasel/kibo/blob/main/packages/choicebox/index.tsx).
Copyright (c) 2023 — Present shadcnblocks.

`src/components/ui/number-field.tsx` adapts the group/input/increment/decrement composition from [ReUI NumberField](https://github.com/keenthemes/reui/blob/main/registry-reui/bases/radix/reui/number-field.tsx), using a native input in place of Base UI. Copyright (c) 2025 Keenthemes Inc.

`src/components/ui/status.tsx` adapts [Kibo UI Status](https://github.com/haydenbleasel/kibo/blob/main/packages/status/index.tsx), with static indicators and study states. Copyright (c) 2023 — Present shadcnblocks.
